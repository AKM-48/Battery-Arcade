# Battery Arcade — Interactive Electrochemistry Demo

An interactive educational mini-site with three scenes:

1. **Flashlight / primary alkaline cell:** switch on, watch the simulated charge decrease, fast-forward and replace the AA battery.
2. **Patrol 4×4 / secondary lead-acid battery:** start the engine, turn on loads, rev and watch the alternator recharge the battery.
3. **Game controller / secondary lithium-ion battery:** play, toggle rumble, connect the charger and use the battery again.

## Open the website

Keep `index.html`, `styles.css` and `app.js` in the same folder. Open `index.html` in a modern browser, or deploy the folder to a static website host.

## Publish on GitHub Pages

Create a GitHub repository, upload `index.html`, `styles.css` and `app.js` to its root, and in GitHub Settings → Pages choose **Deploy from a branch**, `main`, `/ (root)`. GitHub then provides a website URL for the presentation.

## Classroom accuracy

This is an accelerated *conceptual simulation*, not a physically calibrated instrument. Battery percentages, starting drops, discharge and charging times are intentionally exaggerated. A higher engine RPM may improve alternator output when limited at low RPM, but real charging systems regulate voltage and charging rate also depends on electrical load and battery state. Lithium-ion reactions illustrate an idealized graphite–lithium cobalt oxide cell. Do not attempt to recharge disposable alkaline cells.

## Teaching notes

Use **VIEW REACTIONS & EXPLANATION** below each scene to show the chemistry behind oxidation and reduction. Each experiment complements the spoken explanation during the presentation.
